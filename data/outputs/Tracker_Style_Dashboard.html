Methodology

  • Committed: primary-source commitment amount from the register (signed SPA/Subscription Agreement/Capital Account Statement etc.), NOT the tracker's Live/Exited tab - falls back to the tracker's own figure only when no primary-source amount has been confirmed yet.
  • Invested: sum of cash deployments from dated cash flows (CF (Equity, Debt) / CF (Funds) tabs), not the tracker's Live/Exited tab.
  • Distributions: sum of cash distributions from dated cash flows. Shows 0 where there are no distribution records.
  • Carrying Value: latest mark from the tracker's own NAV tab, not the Live/Exited tab.
  • Remaining = Committed - Invested.
  • Gain = Carrying Value + Distributions - Invested.
  • TVPI = (Distributions + Carrying Value) / Invested.
  • IRR (deal and section level): XIRR over the same dated cash flows, with the latest NAV mark as a terminal cash flow.

These match how the tracker's own underlying formulas work (verified directly against its 'A. All deals (a)' tab) - the difference is we compute them from primary sources (register + cash flows + NAV) rather than reading the tracker's own derived output.
